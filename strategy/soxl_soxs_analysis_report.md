# SOXL / SOXS 线性关系建模分析报告

> 数据区间：2018-01-02 → 2026-06-11，共 **2122 个交易日**  
> 分析工具：OLS 线性回归、滚动回归、对数价格分解

---

## 术语速查

| 术语 | 解释 |
|------|------|
| **SOXL** | Direxion 每日三倍做多半导体 ETF，追踪费城半导体指数（SOX）× +3 |
| **SOXS** | Direxion 每日三倍做空半导体 ETF，追踪费城半导体指数（SOX）× −3 |
| **SOX** | 费城半导体指数（PHLX Semiconductor Index），英伟达、台积电等30只芯片股构成 |
| **对数收益率（log-return）** | `ln(今日价 / 昨日价)`，近似于百分比收益率，且具有时间可加性（10天累计 = 10个单日之和） |
| **OLS（普通最小二乘回归）** | 找一条直线 `y = α + β·x`，使所有点到直线的误差平方和最小 |
| **β（斜率 / beta）** | 回归直线斜率。这里表示"SOXL 涨 1%，SOXS 预期变动多少%"。理论值 = −1 |
| **α（截距 / alpha）** | 回归直线截距。非零表示存在系统性偏差（如持有成本、追踪误差） |
| **R²（决定系数）** | 0~1，越接近 1 说明 x 对 y 的解释力越强；0.96 意味着 96% 的 SOXS 收益变动可由 SOXL 解释 |
| **Pearson ρ（相关系数）** | −1~1，ρ = −0.98 表示几乎完美的负线性相关 |
| **残差（Residual）** | 实际值 − 模型预测值。残差越小，模型拟合越好 |
| **滚动回归（Rolling OLS）** | 用最近 N 天的数据滚动估计 β，观察关系是否随时间漂移 |
| **波动率衰减（Volatility Decay）** | 杠杆 ETF 每日再平衡导致的长期净值损耗。震荡行情中多空双边均受损 |
| **对数价格之和（log-sum）** | `log(SOXL价) + log(SOXS价) = log(SOXL×SOXS)`，衡量双边总产品价值 |

---

## 一、为什么不用原始价格，而用对数收益率？

杠杆 ETF 有两大特性使原始价格比较失去意义：

1. **路径依赖**：SOXL 的价格包含了历史所有涨跌的复利效应，与当下 SOXS 价格没有稳定的线性关系。
2. **波动率衰减**：SOXS 在半导体长牛行情中接近归零；SOXL 则大幅上涨。两者量纲完全不可比。

对数收益率消除了这两个问题——它只衡量**今天相对昨天**的变化幅度，与历史价格无关。

---

## 二、OLS 回归结果

回归模型：`r_SOXS = α + β · r_SOXL`

| 参数 | 实测值 | 理论值 | 含义 |
|------|--------|--------|------|
| **β（斜率）** | **−1.0109** | −1.000 | SOXL 涨 1%，SOXS 平均跌 1.011%，追踪良好 |
| **α（截距）** | **−0.004783** | 0.000 | SOXS 每天额外拖累约 **0.48 个基点**（年化约 −1.2%） |
| **R²** | **0.9604** | 1.000 | 96% 的 SOXS 日度波动可由 SOXL 直接解释 |
| **Pearson ρ** | **−0.9800** | −1.000 | 负相关程度极高，接近完美镜像 |
| **残差 σ** | **0.01384** | 0 | 每天约有 ±1.4% 的对数收益率无法被解释（噪声） |

### 关键解读

**β = −1.0109 而非恰好 −1** 的原因：  
SOXS 的年费用率（1.01%/年）略高于 SOXL（0.89%/年），加之做空端的融券成本，导致 SOXS 的实际跌幅系统性地略大于 SOXL 的涨幅。

**α = −0.004783（负截距）的含义**：  
即使 SOXL 当天涨跌为零（r_SOXL = 0），SOXS 平均也会跌 0.48 基点。这是持有成本（费用率 + 做空成本）在收益率上的直接体现，年化约 **−1.2%**，与 SOXS 1.01% 的费用率吻合。

**R² = 0.9604 的含义**：  
剩余 4% 的 SOXS 波动无法由 SOXL 解释，来源于：
- 盘中流动性差异（SOXS 成交量远低于 SOXL）
- 极端行情日的价差放大
- 指数编制与 ETF 再平衡时点的微小错位

## 三、滚动 60 日 β 分析

| 统计量 | 数值 | 含义 |
|--------|------|------|
| 均值 | **−1.0076** | 长期均值与理论值 −1 的偏差仅 0.76%，关系极稳定 |
| 标准差 | **0.0444** | β 的时变波动幅度，约 ±4.4% |
| 最小值 | **−1.3421** | 出现于高波动期（疑为 2020 年 3 月 COVID 暴跌），SOXS 跌幅短暂放大 |
| 最大值 | **−0.8550** | β 向零收缩，说明某段时期两者的镜像关系短暂减弱 |

### 关键解读

- 滚动 β 几乎始终紧贴 −1，说明 ETF 发行商每日再平衡机制**运作正常**，没有发生结构性失效。
- 最大偏离（β = −1.34）发生在**暴跌日密集期**：SOXS 在市场恐慌时反应更猛烈，因为做空杠杆对负方向有更强的凸性放大。
- 最小偏离（β = −0.86）通常出现在**低波动横盘期**：市场窄幅震荡时，两只 ETF 的追踪误差相对放大，线性关系暂时变松。

## 四、对数价格之和（波动率衰减检验）

$$\log(\text{SOXL}) + \log(\text{SOXS}) = \log(\text{SOXL} \times \text{SOXS})$$

**实测趋势：−1.2221 nats/年（约 −70% 的乘积价值/年）**

若两只 ETF 的衰减完全对称，这个值应为常数（斜率 = 0）。

实测斜率为 **负值**，含义：

> 即使 SOXL 在半导体牛市中大幅上涨，SOXS 向零衰减的速度**更快**，  
> 导致两者价格乘积长期下降——这是波动率衰减（Volatility Decay）的直接证据。

### 直觉解释

假设某标的单日涨 10% 再跌 10%，3× 杠杆版：
- 多头 ETF：+30% → −30%，净值 = 1.30 × 0.70 = **0.91**（损失 9%）
- 空头 ETF：−30% → +30%，净值 = 0.70 × 1.30 = **0.91**（损失 9%）

双边各亏 9%，震荡越剧烈、衰减越快。SOX 的高波动率（年化约 35~45%）使 SOXS 衰减速度惊人。

## 五、多空日镜像比率（十分位分析）

将 2122 个交易日按 SOXL 收益率从低到高分为 10 组，计算每组的**镜像比率**：

$$\text{Mirror Ratio} = \frac{r_{\text{SOXS}}}{-r_{\text{SOXL}}}$$

理想值 = 1.0。

- **中间 8 个十分位**：镜像比率紧贴 1.0，说明日常行情中两者追踪精度极高
- **最低十分位（SOXL 暴跌日）**：镜像比率 < 1.0，即 SOXS 的涨幅**小于** SOXL 的跌幅
- **最高十分位（SOXL 暴涨日）**：镜像比率略 > 1.0，即 SOXS 的跌幅**略大于** SOXL 的涨幅

**原因**：极端行情中 SOXS 流动性差，买卖价差大幅扩张，导致实际成交价劣于理论净值，产生系统性滑点。

## 六、实用结论

### 可以做的事

| 用途 | 可行性 | 说明 |
|------|--------|------|
| 用 SOXL 实时估算 SOXS 当日收益 | ✅ 高 | β ≈ −1，R² = 0.96，误差 ±1.4% |
| 用 SOXL 的仓位反推 SOXS 的对冲比例 | ✅ 高 | 1:1 仓位对冲，日度有效 |
| 判断极端行情日 SOXS 是否"追不上" | ✅ 高 | 十分位分析显示暴跌日存在系统性追踪偏差 |

### 不应该做的事

| 用途 | 可行性 | 原因 |
|------|--------|------|
| 基于价格比做统计套利 | ❌ 不可行 | 价格比是趋势性的，无均值回归 |
| 长期双边持有做"对冲" | ❌ 不可行 | 波动率衰减使双边均亏，且 SOXS 加速归零 |
| 利用收益率残差套利 | ❌ 不可行 | 残差 σ = 1.4%，远小于交易成本（≥0.1%/单边） |

---

## 七、一句话结论

> 在**日度对数收益率**空间，SOXL 与 SOXS 表现为近乎完美的 −1 倍线性镜像（β = −1.011，R² = 0.96），  
> 关系由 ETF 每日再平衡机制保证，8 年来极为稳定。  
> 但在**价格层面**，波动率衰减使 SOXS 长期趋向归零，两者价格乘积年均蒸发约 70%，  
> 任何基于原始价格的线性建模或套利思路均无意义。
