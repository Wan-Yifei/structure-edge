## 0 四处站不住的前提，先说清楚

### 0.1 机制支撑的不是这条规则

杠杆 ETF 的再平衡名义额 = `L(L−1) × NAV × r`，**`r` 是当日到收盘的整段收益**，
不是第一个半小时。实测两者同号比例：

```
QQQ 68.4%    SOXL 68.5%    SOXS 67.7%
```

**三分之一的日子，Gao 的信号和机制真正的触发器方向相反。**
「顶刊论文背书 + 机制支撑」这句话的两半指向**两条不同的规则**。

→ **两条都预注册，分主次。** 主检验用 Gao 的 r1；机制信号 `r(09:30→15:30)`
作预先命名的次要检验，临界值按 **max-of-2（t = 1.923）**。

### 0.2 「3x 所以效应更强」在 bps 上是波动率假象，在 IR 上严格中性

SOXL 的收益是 3 倍，**波动也是 3 倍**，t 统计量完全不变。实测尾盘半小时 sd：

```
QQQ 37.4 bps     SOXL 176.3 bps     SOXS 164.9 bps     （4.4–4.7 倍）
```

**报出「SOXL +15 bps vs QQQ +3 bps，符合 3x 预言」是纯噪声也会给出的结果。**
机制真正的主张是关于**标的指数**的，检验它只能比 **IR（D/σ）**，不能比 bps。
成本上也不占便宜：成本/波动 QQQ 0.8%、SOXL 1.2%。

### 0.3 SOXS 不是第三个点

```
SOXL 与 SOXS 的 r1 恰好反号      97.9%（427 个共同交易日）
corr(SOXL 尾盘, SOXS 尾盘)       −0.958
```

它是同一标的的镜像，统计上不提供独立信息。
（唯一的真实价值：`L(L−1)` 对 L = −3 等于 +12 > 0，**预言方向与 SOXL 同号**，
而两者在互补的日子触发，合起来是完整的对称规则而全程只做多 —— 但它被成本杀死，见 §5。）

### 0.4 `k=1` 的前提是**什么都不选**，而这一条才是本研究最值钱的东西

规则由 2018 年的论文**完全指定**，其样本止于 2013；
QQQ 2019-01-02 起与之**零重叠**，且**没有一个参数由我们选**。
**这是能拿到的最强形式的样本外。**

```
k= 1  临界 t 1.691   ← 什么都不选
k= 3  临界 t 2.073   ← 只要再选一样（标的 / 统计量 / 取价方式）
k= 9  临界 t 2.339
k=27  临界 t 2.584   ← 3 信号窗 × 3 持有窗 × 3 幅度过滤
```

**但真正的代价不是这 38% 的门槛涨幅，是「纯样本外」这个性质会被一次性销毁。**
那时就必须真的切留出段，而留出段要花掉一半样本。

→ **扩展网格本次不跑**，临界值算好备查，写进源码。

## 1 面板与口径（锁死）

### 1.1 半小时块的边界（`time_key` 是 bar END，本项目栽过三次）

**同一把尺子**：戳减 1 分钟得到「这一分钟开始的时刻」，再切块、再判 session。

```
09:30–10:00 块 = 戳 09:31 .. 10:00（含），30 根   入场 = 首根 open（= 09:30:00 的价）
15:30–16:00 块 = 戳 15:31 .. 16:00（含），30 根   出场 = 末根 close（= 收盘竞价）
```

实测覆盖：QQQ 1966/1966、SOXL 467/467、SOXS 427/427 **全部恰好 30 根，100%**。
半日市被 `tradeable_days()` 自动剔除（13:00 收盘的日子根本没有 15:30 块）。
**DST 不构成陷阱** —— 09:30/15:30 是墙钟，和小时研究里的隔夜块不同。

### 1.2 必须建**整天 48 格**，不能只建两格

四条审计里的 `external`（望远镜式拼回 buy-and-hold）**要求块划分整个交易日**。
只建两格的话这条检查自动失效，又变成「不会失败的检查」——
上一轮 REVIEW §2.2 就是栽在这里。

- `build_panel` 跨度断言：块长 + 10 分钟（30 分钟块 → 40）
- 被交易的两格要求 **严格 == 30 根**，不是 ≥ 15。覆盖率 100%，零代价，
  但它挡住「7 根 K 线冒充半小时持有」

### 1.3 数据事实

```
重复戳 / 不可能 OHLC：QQQ 0/0、SOXL 0/0、SOXS 0/0
→ 上一轮挂着的「drop_duplicates 会静默吃掉重复戳」在这三个标的上已排除
整个研究在 RTH 之内 → 绕开 premarket 盘外成交那个已知污染源
```

**`backtest_klines.duckdb` 是后复权的。** SOXS 2025-02 记作 3709、现价 48.9 ——
**早期的「价」不是能成交的价**，所以 SOXS/SOXL 的「1 美分 = 多少 bps」地板不可用，
只有尺度不变的 Roll 和实测盘口能用。**QQQ 全程没拆股，美分地板是真的**，
但 1 tick 从 2019 年的 0.70 bps 降到现在的 0.15 bps ——
**成本必须按当天的价算，不能用全样本中位数。**

## 2 两个统计量和一条恒等式

```
p     信号为正的日子占比
L     mean(尾盘半小时 | r1 > 0)   ← 他真正能拿到的
M     mean(尾盘半小时 | r1 < 0)   ← 空头腿，不可执行
U     mean(尾盘半小时)            ← 无条件持有
D     L − M                       ← 信号本身，对漂移严格免疫

恒等式（精确）：  L = U + (1 − p)·D
```

这是上一轮 `μ_h = μ̄ + α_h` 的精确对应物，**而且更好**：
α 是零和的，所以「存在正 α」是零信息；**D 不是零和的，`D > 0` 是一个真命题。**

**三条规矩：**

1. **禁止只报 L。** 每次必须并排给 U 和 `(1−p)D`
2. **若 L 显著而 `(1−p)D` 不显著，正确的产品是「每天无条件买最后半小时」**
3. 三个对照**只有两个自由度**（`U = pL + (1−p)M`），**不得当三条独立证据**

## 3 对照：主对照是「无条件持有」，而这次它真有分辨力

| 对照 | 等价于 | 可交易 |
|---|---|---|
| **(a) 无条件持有 15:30–16:00** | `L − U = (1−p)D` | **是 ← 主对照** |
| (b) 符号随机 | 期望 = U，噪声更大 | 是（只作零校准） |
| (c) 反向信号 | `L − M = D` | 是 |

**为什么不像上一轮的 B′₃ 那样没用：** 上一轮比的是「1 小时切片 vs 8 小时长持」，
两种暴露、噪声基本独立，配对差 CI 宽到 [−4.18, +5.31]。
这次 L 和 U 量的是**同一个 30 分钟窗口、重叠的日子**，
配对差标准误 = `(1−p)·se(D)` ≈ **0.79 bps**，**比 L 自己的标准误还小 31%**。
**主对照的分辨率高于主估计本身。**

## 4 成本：实测校准，并修好一个时钟假设

### 4.1 时钟陷阱（本轮最该被记住的副产品）

**`db/order_book.db` 的 `ts` 是 ET 墙钟**，和 `time_key` 同一把尺子。
用 QQQ 盘口中价对 1 分钟 K 线做偏移扫描：

```
+0 分钟 → 中位 |差| 2.342 bps
+1 分钟 → 中位 |差| 0.452 bps   ← 唯一对上的（bar-END 导致的 1 分钟）
+2 分钟 → 中位 |差| 2.564 bps
```

**按 UTC 切会把盘后价差当成盘中价差读，而且数字看着很像回事。**

### 4.2 Roll 的偏倍数已校准 —— 上一轮挂了两轮的待办关掉了

```
                15:30–16:00 实测盘口          Roll(1984)
QQQ    中位 0.303 bps = 2 tick（$661.41）      2.42  ← 高估 8.0 倍
SOXL   中位 2.046 bps = 1 tick（$48.91）       3.11  ← 高估 1.5 倍
```

**上一轮怀疑的「Roll 把均值回复当成了价差」被坐实。
结论：Roll 只能当上界用，不能当价差数值引用。**

这件事是决定性的：QQQ 的 80% 功效幅度 2.93 bps。
用 Roll 的 2.42，成本占掉 83%，这格几乎自动出局；用实测的 0.30，只占 10%。

### 4.3 执行方式与成本档

实际执行：**15:30 可成交限价单进场，15:50 前挂 MOC 出场**。
MOC 拿到收盘竞价价，**出场不穿价差**。16:00 那根 bar 的成交量是盘中分钟的
**10.3 倍**（SOXL 12.4 倍，SOXS 只有 3.2 倍 —— 又一条 SOXS 不可用的线索）。

```
QQQ   0.00 / 0.15 / 0.30 / 0.61 / 2.42（Roll，标注「已知高估 8 倍，是上界不是价差」）
SOXL  0.00 / 1.00 / 2.05 / 3.11
SOXS  0.00 / 13.5 / 17.0
```

**全档并排报 + 零成本外推。结论若依赖哪一档则结论无效**
（ORB 那轮 B 统计量正比于成本常数，栽过）。

## 5 资格：事先声明哪些腿不能产出判定

| 腿 | 触发率 | 成本 | 需要的毛幅度 | 真值等于门槛时的检出率 | 裁定 |
|---|---|---|---|---|---|
| **QQQ 多头** | 53.4% | 0.30 | 5.00 | **~100%** | **主检验** |
| QQQ 的 D | — | — | — | MDE80 = 4.29 | 机制腿 |
| SOXL 多头 | 51.4% | 2.05 | 6.91 | **18%** | 功效不足，只作描述 |
| SOXS 多头 | 47.1% | 17.0 | 22.31 | — | **成本出局** |
| SOXL+SOXS 合并 | 100% | 9.87 | 11.83 | **43%** | 功效不足，只作描述 |

SOXS 的干净算法：把 QQQ 能分辨的最大效应（4.29 bps）按波动比 4.41 放大 = 19.0 bps 毛，
减 17.0 成本 = 2.0 bps/笔 × 47.1% = **0.94 bps/天，对着 2.5 的门槛**。
**即使效应是真的、且大到 QQQ 分辨力的上限，SOXS 也赚不到门槛。**

→ **只有 QQQ 能产出判定。这和「3x 才是效应所在」的直觉正好相反，原因在 §0.2。**

## 6 门槛：每笔 4.68 bps，不是每天 2.5

```
2.5 bps/天 × 252 = 6.3%/年   ← 这个门槛当初按「天天做」定的，衡量的是年化贡献
本规则触发 53.4% → 每年约 134 笔
同样的 6.3%/年需要每笔净 2.5 / 0.534 = 4.68 bps
```

理由：跟资金和注意力竞争的是**年化贡献**。按每笔 2.5 卡，
一条触发率 10% 的规则也能「通过」，而它一年只贡献 0.63%。**两个数都报，判定用 4.68。**

**门槛必须高于 MDE**（上一轮条件 6 的教训）：MDE80(L) = **2.93 < 4.68**，满足。

**一条有用的推论**：要让**信号本身**撑起 4.68 bps，需要 `D ≥ 4.68/(1−p) = 10.0 bps`，
而 MDE80(D) 只有 4.29 bps —— **需要的幅度是分辨力的 2.3 倍**。

> **所以：这条规则能过就会过得很响；过得勉强，那它是漂移不是信号。**

## 7 零分布：置换信号，不是翻符号

**把信号向量按交易日块置换**（保持触发日数），`block=5`，20000 次，种子 20261116。

比符号翻转更合适：它**完整保留尾盘收益的边际分布**（肥尾、波动聚集、漂移全保留），
只摧毁配对 —— 正是「第一个半小时对最后一个半小时不含信息」这个零假设的
**精确有限样本检验**。

```
标的    n     k=1 临界 t（iid / block-5）   MDE50(L) / MDE80(L)
QQQ    1966      1.634 / 1.691                1.96 / 2.93
SOXL    467      1.625 / 1.636               15.91 / 24.05
SOXS    427      1.651 / —                   20.53 / 31.02
```

用 **block-5 的 1.691** —— QQQ 的 `sign(r1)` 有真实的日间负自相关（−0.065，t ≈ −2.9）。
置换临界值 ≈ 正态的 1.645，**说明 t 近似在这个数据上站得住**，这本身是个值得报的零结果。

## 8 横截面预言：不能进主检验，而且根本量不出来

**(1) 2 个点的排序在零下只值 1 bit。** `P(D̂_SOXL > D̂_QQQ | H0) = 1/2`。

**(2) 必须同窗口同口径比，那样分辨率就没了。**

```
QQQ 全样本     MDE50(D/σ) 0.0746
QQQ 共同窗口   MDE50(D/σ) 0.1559     SOXL 0.1546
(IR_SOXL − IR_QQQ) 抽样 sd = 0.1070 → 横截面差 MDE50 = 0.176 IR、MDE80 = 0.266 IR
```

**要看见这个横截面差，效应得比整个研究在 QQQ 上能分辨的最大效应还大 2.4–3.6 倍。
这不是「弱证据」，是「用现有数据不可测」。**

**但它可以证伪、不能证实**，预注册成：

```
QQQ 显示效应 而 SOXL 的 IR 点估计明确为负（不只是不显著）
   → 对「杠杆 ETF 再平衡」这个机制是反证（但不否定效应本身）
SOXL 显示、QQQ 不显示 → 与机制相容，但 SOXL 自己的功效说明不了问题（§5）
其余四种组合          → 无信息，事先声明不解读
```

## 9 通过标准：七条

**主检验锁死：QQQ / 多头腿 L / 09:30–10:00 → 15:30–16:00 / 单侧 / 全样本 / 最差成本档。**

```
1  t(L) > 1.691                         （k=1，交易日块置换零分布，种子 20261116）
2  (1−p)·D 的 95% 单侧下界 > 0            归因：是信号不是漂移
3  L − 最差档成本 的 95% 单侧下界 > 0
4  L − U（配对按日自助）的 95% 下界 > 0    ← 主对照
5  逐年刀切：去掉贡献最大的那一年后 ≥ 全样本点估计的 50%
6  L − 成本 ≥ +4.68 bps/笔
7  机制：能说出一条可测的因果链，并且它被测了（§10）
```

**三种结局跑前各有名字，全部单侧**（上一轮那一处单双侧不一致正好值 0.27 bps，
刚够把「排除」变成「既不通过也不排除」）：

```
单侧 95% 上界 < 4.68   → 「排除」
上界过门槛而下界跨零   → 「既不是通过，也不是排除」
七条全成立            → 「通过」
```

### 9.1 条件 5 为什么是刀切而不是前推

**「扩展窗口前推」在 k=1 上定义不成立** —— 没有选择，就没有「用历史选、往后交易」
这回事。**必须在这里明说，否则后面的会话会凭空造一个数出来。**

替代品三件，只有一件是闸门：

- **5a 来源即样本外（性质，不是闸门）**：论文样本止于 2013，本样本 2019 起，零重叠，
  且没有一个参数由我们选。**条件是 k 保持为 1。**
- **5b 逐年刀切（闸门）**：动机是实测事实 —— **QQQ 尾盘半小时方差 2020 年一年占 50.7%**
  （2019 3.4 / 2020 50.7 / 2021 5.7 / 2022 15.6 / 2023 5.7 / 2024 6.4 / 2025 8.2 / 2026 4.5）。
  零分布已算：纯零之下、全样本为正的复制里，去掉最伤的一年后保留比例
  中位 0.32、p25 0.02、p05 −0.50 —— **「保留 ≥ 50%」只放过 31.2% 的纯噪声赢家**。
  **这是一条有真实分辨力的闸门**（对比上一轮的 B′₃，那条什么都分辨不了）。
- **5c 逐年净值曲线**：只作描述，并排印纯零分位带。

### 9.2 缩尾与杠杆

单日最极端观测对均值的推动：**QQQ 0.272 se、SOXL 0.282、SOXS 0.238**
（上一轮锁定的 8 格全部 ≤ 0.10）→ **这一轮缩尾比上一轮重要得多**。
0.5% 双侧缩尾预先声明，**两版并报；不一致则这个发现是一根价不是一个效应**。

斜率检验另有独立的杠杆问题（hat 值只由信号决定）：

```
            最大 hat    = 平均日的倍数   前 10 天占总杠杆
QQQ         0.0192         37.7×            13.0%
SOXL        0.0643         30.0×            25.6%
SOXS        0.1026         43.8×            29.1%   ← 一天占 10.3%
```

→ **斜率检验只在 QQQ 上做，且信号与结果同时缩尾，两版并报。**

### 9.3 为什么主统计量用原始 bps 等权

2020 年占 QQQ 一半方差，按精度加权能把 se 砍 27.5%，很诱人。
**但机制自己否决了这个做法**：再平衡名义额 ∝ 当日涨幅，**效应本身就该随波动放大**，
那正是等权在 bps 上的假设；而且等权的 bps 才是他实际赚到的钱。

→ 主检验锁死等权原始 bps；波动率标准化版本作**预先命名**的敏感性档，
计入 k（max-of-2，临界 t 1.923），**不得用它去救一个失败的主检验**。

## 10 机制探针（条件 7）

机制说再平衡流大量走收盘竞价 → **效应应该集中在最后几分钟，而不是均匀摊在 30 分钟上**。
预注册**一个**对比：

```
D 在 15:55–16:00 的每分钟速率  vs  D 在 15:30–15:55 的每分钟速率，单侧，预言前者更高
QQQ  15:30–15:55 sd 31.1 bps MDE50(D) 2.33 → 每分钟 0.093
     15:55–16:00 sd 16.1 bps MDE50(D) 1.18 → 每分钟 0.235
→ 要看见差别，最后 5 分钟的速率得比前 25 分钟高约 2.5 倍。powered 但不宽裕。
SOXL 对应 0.850 / 2.601 —— 功效不足，不做。
```

**这条探针不能把失败的主检验变成通过。** 它的作用是单向的：
主检验通过 + 探针通过 = 有机制的发现；
**主检验通过 + 探针失败 = 没有机制的 1/20 命中**，按本项目自己的教训（吸收标记那轮）
不值得做。

## 11 这个方案不回答什么

1. **QQQ 2019–2026 到底有没有日内动量。** 1–2 bps 量级需要 34–137 年样本
   （D=1.0 → 34,648 天；D=2.0 → 8,662 天；D=4.31 → 1,966 天，恰好是我们有的）。
   **本研究只能回答「够不够这个人做」（需要 D ≥ 10 bps）。两件事一个字都不能混。**
2. **机制是不是杠杆 ETF 再平衡。** 横截面不可测（§8），探针只能分辨 2.5 倍速率差。
   即使七条全过，「为什么」仍然未定 —— **Gao 自己给的解释就不是这个**。
3. **Gao 的结果在毛收益口径下成不成立。** 只回答净收益口径（沿用上一轮分工）。
4. **效应有没有在发表后衰减。** 没有 2013 年前的数据，做不了「发表前 vs 发表后」。
5. **半导体复合体上有没有这件事。** 三条腿功效 18%–43%，
   **「不确认」等于「本来就确认不了」，不是证据**（上一轮 §5 的教训）。
6. **做空那半边值不值得。** 他不做空；SOXS 路线被 17 bps 成本杀死。
