# 初始平衡区间（initial_balance）研究方案

2026-11-16。**方案文档。** 定稿时一笔「宽窄 → 后续收益」的条件均值都没算过。

**命名**：`initial_balance` = 开盘后头一段的高低区间（拍卖市场理论的说法）。
**不是隐含波动率（IV），也不是用户管 `strategy/session_vp/` 叫的 IVB** ——
三个名字两两差一个字母、指的不是一回事，**代码和文档里一律写全称，不用缩写**。

代码：`strategy/initial_balance/rule.py` + `backtest/initial_balance.py`，
面板复用 `strategy/intraday_bias/panel.py`（30 分钟块）。
每次运行的格子清单写在 `backtest/results/<时间戳>_initial_balance/PREREG.md`。

## 0 四条站不住的前提（全部实测，全部不涉及条件收益）

### 0.1 「宽幅 → 当天波动已走完」——**测反了**

```
QQQ，L=40 滚动中位分类     区间中位      10:00→16:00 剩余高低幅中位   剩余/区间
窄日                       44.9 bps            106.0 bps              2.29
宽日                       81.2 bps            135.4 bps              1.64
```

**宽日剩下的绝对波动更大，不是「走完了」。** 真实差异在**比例**上，
而那个比例差本身有一个无趣的解释：**用 30 分钟估一天的波动本来就是噪声估计，
低抽样自然向上回归** —— 这是测量的均值回归，不一定是市场的机制。

→ 「窄日能量未释放」**没被证伪**（注意措辞），「宽日波动走完了」**被证伪**。

### 0.2 它不是一个有选择性的触发器

```
30 分钟区间只装下全天高低幅的 45.7%（中位）
突破上沿：窄日 76.2% 触发，宽日 71.7%     ← 差 4.5 个百分点
99.4% 的日子里，10:00 之后价格至少打掉一边
```

把「固定小时盲买」换成这个，不是换成了状态触发，是换成了**「盲买 + 一段入场滑移」**。

### 0.3 必须写死的机械恒等式 —— `feedback_control_same_ruler` 第三次

出场都是同一根收盘价，所以：

```
突破腿  log(C/E)  = log(C/O10) − dist_up    dist_up ≥ 0   窄 20.1 / 宽 31.3 bps
回归腿  log(C/Lo) = log(C/O10) + dist_dn    dist_dn ≥ 0   窄 18.4 / 宽 37.0 bps
```

**突破腿天生落后、回归腿天生领先，两条腿的机械起跑线差 38（窄）到 68（宽）bps。**

1. **突破腿赚钱的唯一途径是躲开不触发的日子**，不是「突破有动量」。这是恒等式，不是修辞。
2. **raw 口径下「回归腿看着比突破腿好」是被构造保证的**，和谁对无关。
3. → **判定统计量必须是对照调整后的 A，任何 raw 比较都是在比这两个常数。**

### 0.4 「格子重叠所以临界值会低很多」——**错**

实测 27 格（3 区间长 × 3 回看 × 3 分位），同一套按交易日块的符号翻转：

```
格间平均两两相关      +0.787      （小时研究只有 +0.01）
实测 max-t 95 分位     2.641
Bonferroni-27 上界     2.782       → 折扣只占缺口的 12.4%
```

**相关 0.787 这么高，折扣还是几乎为零。能省 t 的只有跑前锁旋钮，不是指望折扣。**

## 1 旋钮：从 81 格砍到 2 格，每一刀的依据写明

| 旋钮 | 砍掉的依据 | 计入 k？ |
|---|---|---|
| 区间长度 15/30/60 | **真先验**：用户本来就以 30 分钟看盘，在看任何收益之前说的 | 否（60 作敏感性档） |
| 窄宽判据 | **构造上的必然**（§2 三条） | 否 |
| 回看长度 L | **收益盲判据**：满足「每个自然年窄日占比 50%±10%」的**最长**窗口 → **L=40** | 否 |
| 窄宽阈值 | 中位是唯一按构造平衡、且不额外产生「中间档」的切法 | 否（构造理由） |
| 突破定义 | 「触及即成交」需要 bar 内成交假设，查不了；**1 分钟收盘穿越 + 下一根开盘成交**是唯一无 bar 内前瞻的写法 | 否 |
| 出场 | ORB 实测：30 分钟区间下 **74.3% 的交易两边障碍都碰不到** → 障碍不约束却多付 2 个旋钮；MOC 还不穿价差 | 否 |
| **被判定的腿** | **用户事先点名的两条** | **是，k=2** |
| 标的 | SOXL/SOXS 门槛处功效 4–5% | 否（事先声明不判定） |

**实测临界 t**（交易日块符号翻转，20000 次，种子 20261117）：
`k=1 → 1.637`、**`k=2 → 1.980`**、`k=4 → 2.264`。

**锁旋钮省下 2.641 → 1.980 = 0.66 个 t 单位；指望折扣只能省 0.14。**

**一条被明确禁止的做法**：**不得用 ORB 那轮（`doc/orb_research.md`）的结果挑本轮任何参数** ——
同一批数据同一个样本，那等于把选择藏到上一轮，临界值的代价一分没省。
ORB 只能提供**描述性约束**（74.3% 不碰障碍、分母塌陷的结构）。

## 2 「窄」「宽」怎么定义：滚动分位，绝对口径被实测否决

- **(a) 隔夜跳空比 —— 构造上出局。** 分母可趋近于零，正是 ORB 栽过两次的结构
  （对照腿 `cost_R` 冲到 25 个 R，决定性统计量变成成本常数的正比例）。
- **(b) 绝对百分比 / 扩展窗中位 —— 被制度混淆否决。** 扩展窗中位下 QQQ 的窄日占比
  **2022 只有 9.6%，2024 有 71.9%** —— 「窄 vs 宽」一大半是「牛市 vs 熊市」。
- **(c) ATR 比 —— 多一个周期旋钮，量的是同一件事。**
- **(d) 滚动分位（锁死）**：`narrow[d] = range[d] < median(range[d−40 .. d−1])`，
  只用过去，无前瞻。实测逐年窄日占比 **0.46–0.59**，平衡。

**必须写明**：这把尺子把命题从「绝对意义上窄」换成了**「比最近 40 天安静」**。
我认为后者才是「波动率压缩」的本意，但**这是一次口径替换，不能默认两者是一回事**。

区间不会塌向零（QQQ 最小 14.2 bps、p01 22.4），所以用它做分母安全。

## 3 这是两条规则，分开判，k×2

1. 两条腿跑在**互斥的日子集合**上 → 近似独立 → max-of-2 实测 1.980。
2. **不是小时研究 §9 那种零和同义反复** —— α 零和所以「存在正 α」是零信息；
   这里两条腿**都是多头**，不存在「一边必须为负」的代数约束。
   **「总有一边对」这个担心在代数上不成立。**
3. **但它换了形式回来**：§0.3 的机械起跑线差。→ **判定必须用 A，不是 raw。**

**反向配对（窄×回归、宽×突破）一起报但不判定。** 如果反向看着一样好，这个 2×2 就是噪声。
它们一旦被提升为判定对象，临界 t 从 1.980 升到 **2.264**。

## 4 对照：同一天、同一个收盘、同一批日子

**主对照：同一批日子里「10:00 买、16:00 MOC 平」。** 共享标的、方向、日子集合、
出场价、成本结构 —— 唯一不同的是「要不要等那个触发」。
这正是 `feedback_control_same_ruler` 要求的「指定什么相等」。

```
A = E_class[ 1{触发}·log(C/E) ] − E_class[ log(C/O10) ]     未触发记 0，不付成本
```

**为什么不能只看 raw**：10:00→16:00 的无条件漂移 QQQ ≈ **+1.4 bps/天**，
是 2.5 bps/天门槛的 **54%**。小时研究里漂移占门槛 18%、排威胁榜最后；
**这一轮它排不了最后。**

### 4.1 成本方向是反的 —— 这一条必须写死

规则在约 30% 的类内日**不在市**，对照天天在市，**所以对照付的成本比规则多，
提高成本假设会让 A 变好看**。

→ **A 的保守端是零成本，规则自身收益的保守端是最高档。两个统计量各用各的保守端。**
ORB 那轮的 B 统计量正比于成本常数；这是同一个陷阱反过来的样子。

## 5 成本：这一轮成本**决定不了**结局

```
QQQ 1 tick 按当天价折算：2019 0.56 → 2026 0.14 bps（4 倍趋势，不能用全样本中位价）
档位 0 / 1 / 2 / 4 tick = 0.000 / 0.305 / 0.610 / 1.221 bps
每笔门槛约 5–7 bps → 成本占 2%–8%
```

→ **结论不可能依赖成本档**，也意味着 **Roll 高估 8 倍这件事这一轮不影响判定**
（与小时研究相反，那轮成本 ≥ MDE 直接关掉了 16 格）。

## 7 样本外：扩展窗前推不成立，时间留出没有功效

```
                   n     se     MDE80   真值=门槛时通过率
全样本 窄×突破    955   1.85    5.17        76%
前半              467   2.85    7.99        42%
后半              488   2.37    6.64        53%
→ 80% 功效的留出段需要再攒 8.3 年
```

1. **50/50 时间留出不能当闸门** —— 把 76% 功效的检验换成 42% 的，「不确认」什么都不说明。
   **可以报，必须标「描述，不参与判定」。**
2. **「来源即样本外」这一轮没有**（动量那轮的 k=1 来自论文完全指定）。必须明说。
3. **但有一件事是真的、容易被说反**：分类用的是**滚动**中位数，只用过去 40 天 ——
   **规则本身已经是在线规则，全样本就是这条规则的前推。
   不在样本外的是旋钮的选择，不是规则的执行。** 两件事不要混。
4. **实际用的闸门：逐年刀切**，去掉最伤的一年后保留 ≥ 50%。
   纯零之下实测只放过 **28.3%** 的噪声赢家 —— 和动量那轮的 31.2% 同级，是真闸门。
5. **前瞻性留出，门槛现在冻结**：再攒 **250 个窄日（≈2 年）** 后重跑，
   档位、临界 t 1.980、种子 20261117 现在写死。

## 8 通过标准：七条

**主检验锁死：QQQ / 单侧 / 全样本 / A 用零成本档、规则自身收益用最差档。**

```
1  t(A) > 1.980                     k=2，交易日块符号翻转，种子 20261117
2  A 的 95% 单侧下界 > 0
3  A ≥ 判定档位 max(经济门槛, MDE80)
4  规则自身收益（最差成本档）的 95% 下界 > 0   别报一个赢了对照却亏钱的规则
5  逐年刀切：去掉最伤的一年后 ≥ 50%            纯零放行率 28.3%
6  缩尾版与不缩尾版同号且相差 < 50%            单日最大杠杆实测 0.15–0.18 se
7  **机制**：能说出一条可测的因果链，而且它被测了、没被证伪（§9）
```

**三种结局跑前各有名字，全部单侧**：
单侧 95% 上界 < 判定档位 → **排除**；上界过档而下界跨零 → **既不通过也不排除**；
七条全成立 → **通过**。

## 9 机制：最显眼的那条**在设计阶段就被测成零**

假说 A：「压缩 → 止损挂在区间外沿 → 突破被放大」。
可测推论：**突破后 10 分钟的已实现波动相对突破前 10 分钟的放大幅度，窄日应高于宽日。**
已实现波动**没有方向**，所以这个探针不可能是主检验的变装。

```
QQQ，L=40，突破前后各有 10 根干净分钟的 800 次突破
       n     前 bps/分   后 bps/分   log(后/前)      se
窄日  434      3.98        3.35       −0.1903      0.0193
宽日  366      5.76        4.36       −0.2133      0.0194
窄 − 宽 = +0.0229   se 0.0274   t = +0.84   MDE80 = 0.0767
```

**两类日子突破后波动都减速 17–19%，不是加速；窄宽之差是零，而探针能分辨 8% 的相对差。**

（减速的**绝对水平**不可解读 —— 突破点是被「第一根穿越的收盘」选出来的，前窗必然含着那一下。
但**窄宽之差**两边选法相同，可解读。）

假说 B（§0.1）：「压缩 → 当天剩余波动按比例更大」。**没被证伪**，
但同一个数也能由「30 分钟估波动的噪声向上回归」产生，**不构成机制确认**。

→ **条件 7 跑前就处在高风险位置。** 本项目自己的教训（吸收标记那轮）说明**先说机制再测**。
**把 §9 这条已测为零的当机制引用，是不诚实的。**

## 10 这个方案不回答什么

1. **QQQ 2019–2026 到底有没有「开盘区间宽窄 → 日内方向」的效应。**
   只能分辨 ≥ 6–8 bps/类内日。1–2 bps 量级需要 60–240 年。
   **本研究回答「够不够这个人做」，不是「这件事存不存在」。一个字都不能混。**
2. **带止损止盈的版本。** 出场锁死 MOC。
   **bps 口径的结论与 R 口径的结论不得互相引用**（小时研究 §3 的警告）。
3. **真正的均值回归**（回到区间中轴 / VWAP 止盈）。本方案的「宽日回归」实际测的是
   「宽日里跌到区间下沿的，到收盘能不能涨回来」，**不是回归到某个目标**。
   加目标就是再加两个旋钮，临界 t 会跳到 2.6 以上。
4. **半导体复合体上有没有这件事。** 功效 4–5%。
5. **做空那半边。** 用户只做多。

   动量那轮的「QQQ 15:30–16:00 中位 0.303 bps」本次没能复现，只作量级引用。
   **不影响判定**（成本只占门槛 2–8%）。
2. **条件 7 的机制还没有。** §9 把最显眼的那条测掉了。
3. **app / 实盘条件（第 N 次）**：这条规则需要 (a) 10:00 判宽窄 ——
   要 **40 个交易日的 30 分钟区间历史**，而 viewer 的 Range 默认只加载 1–5 个 session
   （`RANGE_DAYS`，记忆 `feedback_verify_in_app`）；(b) 10:00 之后的**盘中持续监控**
   （突破中位在第 18 分钟触发，不是一次性提醒）；(c) 15:5x 的 MOC。
   **scheduler / signal scanner 里三件都没有对应物。
   「离线成立、工具里做不出来」这个风险这一轮比前两轮大，因为触发是盘中的。**
4. **`feeds/fetcher.py` 分页 bug 挂了四轮。**
5. **后复权**：SOXL 的「1 tick = 多少 bps」2025 是 3.71、2026 是 0.89，**差 4 倍**。
   **SOXL/SOXS 的美分地板不可用，本方案只在 QQQ 上做成本判定。**

## 12 纪律

**本文件里任何数字都不得进 CHANGELOG 或记忆，直到判定跑完。**

**两条例外，是数据/方法事实而不是策略结论，分开写：**

1. **格子高度重叠买不到多少折扣**：27 格平均相关 +0.787，实测 max-t 2.641 vs
   Bonferroni 2.782，**折扣只占缺口的 12%**。
   **这推翻了「重叠格子可以不校正」这个在 ORB 那轮被默许过的直觉。**
2. **开盘区间的机械恒等式**：MOC 出场下
   `log(C/E) = log(C/O10) − dist_up`、`log(C/Lo) = log(C/O10) + dist_dn`，
   QQQ 上 dist 是 18–37 bps。
   **任何「突破 vs 回踩/回归」的对比，不做对照调整就是在比这两个常数。**
   这条应该推广到 IVB（`strategy/session_vp/`）的 VAL→POC 规则上去查一遍。
