# 订单流判读指南 — Heatmap、Delta 与 K 线形态

---

## 一、理论基础：订单流的本质

每一笔成交都由**两方**完成：

| 角色 | 下单方式 | 含义 |
|------|----------|------|
| **主动方（Aggressor）** | 市价单 / 吃单 | 急于成交，接受当前报价 |
| **被动方（Passive）** | 限价单 / 挂单 | 等待价格到达，提供流动性 |

- **Buy Volume**：成交在卖一价（Ask）——买方主动出击
- **Sell Volume**：成交在买一价（Bid）——卖方主动出击
- **Delta = Buy Volume − Sell Volume**

Delta 揭示的是**谁更"急"**，但 Delta 本身不决定方向——必须结合 K 线形态与结构综合判断。

---

## 二、Heatmap 颜色编码

Heatmap 根据每根 K 线的 Delta 对蜡烛着色，颜色独立于 K 线本身的涨跌：

```
  价格轴
    │
    │   ┌───┐  ← 金色蜡烛（#FFA005）
    │   │▓▓▓│    Delta 大幅正值：买方主动成交占优
    │   │▓▓▓│
    │   └───┘
    │
    │   ┌───┐  ← 紫色蜡烛（#AB47BC）
    │   │░░░│    Delta 大幅负值：卖方主动成交占优
    │   │░░░│
    │   └───┘
    │
    │   ┌───┐  ← 青/灰色蜡烛
    │   │   │    Delta 接近 0：买卖平衡 / 量极低
    │   └───┘
    └────────────────────────────────── 时间轴
```

**核心原则：Heatmap 颜色 ≠ K 线涨跌颜色**

```
  下跌 K 线（收盘 < 开盘）+ 金色  →  价跌但买方在吸筹（关键信号）
  上涨 K 线（收盘 > 开盘）+ 紫色  →  价涨但卖方在出货（关键信号）
```

这种"颜色与涨跌方向不一致"的情形，是最有价值的信息。

## 三、Delta 的三种核心模式

### 3.1 顺势确认（Aligned Delta）

```
  价格  ▲               Delta  ▲
        │  /\                  │  +8K
        │ /  \                 │  +5K
        │/    \                │  +3K
        └──────▶ 时间           └──────▶ 时间

  价格上涨 + Delta 持续正值  →  买方真实推动，趋势健康，可顺势做多
  价格下跌 + Delta 持续负值  →  卖方真实推动，趋势健康，可顺势做空
```

### 3.2 Delta 背离（Divergence）——最重要的转折信号

**看涨背离**：价格创新低，但卖方力量在减弱

```
  价格  ▼
    ────┐            ┌──── 低点 2（更低）
        └────────────┘

  Delta    −30K         −5K
           ████         █       ← 卖方"弹药"骤减
           ████
           ████

  解读：卖方虽然在继续压价，但主动卖单大幅减少
        → 被动买方（限价单）在低位大量承接
        → 潜在见底，卖力衰竭
```

**看跌背离**：价格创新高，但买方力量在减弱

```
  价格  ▲
        ────────────┐            ┌──── 高点 2（更高）
                    └────────────┘

  Delta    +25K         +2K
           ████          █       ← 买方"弹药"骤减
           ████
           ████

  解读：买方虽然在继续推价，但主动买单大幅减少
        → 被动卖方（限价单）在高位大量出货
        → 潜在见顶，买力衰竭
```

### 3.3 吸收（Absorption）——机构级操作

```
  价格  ─────────────────────── （几乎不动，实体极小）

  成交量  ████████████████████  （异常放量）

  Delta   +15K  −18K  +12K  −14K  （剧烈波动但抵消）

  解读：有大量限价单在此价位挂单，将所有市价单悉数吸收
        价格难以突破 → 该价位有机构防守
        若吸收发生在支撑位（底部大量买单承接市价卖单）→ 看涨
        若吸收发生在压力位（顶部大量卖单承接市价买单）→ 看跌
```

## 四、K 线形态 × 订单流组合判读

K 线形态描述**价格的结果**，Delta 揭示**驱动力的来源**，两者结合才能区分真实信号与陷阱。

---

### 4.1 锤子线 / 大阳线 + 正 Delta ✅ 强看涨

```
       │  ← 上影（少量卖压，已被消化）
    ┌──┴──┐
    │ ███ │  ← 金色（买方主导）
    │ ███ │
    └──┬──┘
       │  ← 下影（买方强力反击）

  Delta: +12K  ← 配合实体，买方真实推动

  意义：价格从低位大力反弹，下影显示卖方尝试压价失败，
        正 Delta 确认买方是主导力量，非被动反弹。
  操作：可在此 K 线收盘后寻找做多机会，止损置下影低点之下。
```

---

### 4.2 锤子线 / 大阳线 + 负 Delta ⚠️ 警惕陷阱

```
       │
    ┌──┴──┐
    │ ░░░ │  ← 紫色（卖方主导）！
    │ ░░░ │
    └──┬──┘
       │

  Delta: −8K  ← 与 K 线方向相反！

  意义：价格虽然形成阳线，但卖方主动成交更多
        → 阳线是被动买单（限价单）推出来的，并非买方主动追价
        → 反弹力度存疑，可能是"死猫弹"或出货
  操作：不宜追多，等待后续确认（下一根 K 线 Delta 是否转正）。
```

---

### 4.3 射击之星 / 大阴线 + 负 Delta ✅ 强看跌

```
       │  ← 长上影（买方尝试突破，被卖方狙击）
       │
    ┌──┴──┐
    │ ░░░ │  ← 紫色（卖方主导）
    │ ░░░ │
    └─────┘

  Delta: −18K  ← 卖方强力压制

  意义：上影越长，说明买方曾经尝试突破但失败越彻底。
        负 Delta 确认卖方是主动施压方。
  操作：可在此 K 线收盘后寻找做空机会，止损置上影高点之上。
```

---

### 4.4 射击之星 / 大阴线 + 正 Delta ⚠️ 可能是洗盘

```
       │  ← 长上影
       │
    ┌──┴──┐
    │ ███ │  ← 金色（买方成交居多）？
    │ ███ │
    └─────┘

  Delta: +6K  ← 与 K 线方向相反！

  意义：价格下跌但买方主动成交更多
        → 可能是大量限价卖单在高位挂着，承接了所有买单
        → 也可能是价格快速从高位被"吸收"后回落
  判断：看 Vol Profile 是否在此价位有高量节点
        若有 → 机构限价卖单吸收，做空仍有效
        若无 → 异常，等待观察
```

---

### 4.5 十字星 + 极低 Delta + 高成交量 ✅ 吸收 / 转折

```
       │  ← 上影
    ───┼───  ← 开收盘接近（实体极小）
       │  ← 下影

  成交量: ██████████████  ← 异常放量
  Delta:  +200  ← 接近 0（买卖几乎对等）

  意义：双方在此价位激烈博弈，但没有一方能推动价格
        高成交量 + 接近 0 的 Delta = 大量限价单吸收了所有市价单
        → 此价位有机构防守，重要支撑/压力
  操作：结合前后方向判断。若在下跌趋势末端出现 → 看涨吸收，底部信号。
                           若在上涨趋势末端出现 → 看跌吸收，顶部信号。
```

---

### 4.6 连续同向 K 线 + Delta 递减 ⚠️ 趋势衰竭

```
  价格  ▲          ▲          ▲
     ┌──┴──┐    ┌──┴──┐    ┌──┴──┐
     │ ███ │    │ ███ │    │ ███ │
     └─────┘    └─────┘    └─────┘

  Delta:  +20K       +8K       +2K
          ████        ██         █   ← 递减！

  意义：价格在继续上涨，但每根 K 线的买方动力越来越弱
        → 趋势末期，买方正在放弃追高
  操作：不宜继续追多，准备观察卖方是否接管（等负 Delta 出现）。
```

## 五、Heatmap 分层解读：同一根 K 线内的颜色组合

Heatmap 是**逐价格 bin 着色**（`ratio = (买量 − 卖量) / (买量 + 卖量)`），颜色深浅还反映该 bin 的绝对成交量。因此一根 K 线内可以同时出现金色和紫色区域，携带比整体 Delta 更细粒度的信息。

### 核心参照：收盘价所在 bin 的颜色最重要

无论 K 线涨跌，**收盘价附近 bin 的颜色**揭示的是"谁最终掌控了价格"：

| 收盘 bin 颜色 | 含义 |
|---|---|
| **金色（买主导）** | 收盘时买方仍在主动出击，价格的"结局"由买方写就 |
| **紫色（卖主导）** | 收盘时卖方主动施压，价格被推到了卖方希望的位置 |

---

### 5.1 下跌红 K 线：上金下紫 ✅ 强看跌（最常见下跌结构）

```
  开盘（顶）
  ┌────────────────────────┐
  │ ███████████████████████│  ← 金色：开盘附近买方主动（但失败了）
  │ ███████████████████████│
  ├────────────────────────┤
  │ ░░░░░░░░░░░░░░░░░░░░░░░│  ← 紫色：价格被卖方持续压低
  │ ░░░░░░░░░░░░░░░░░░░░░░░│
  └────────────────────────┘
  收盘（底）                    Delta: 负值

  叙事：买方在高位（开盘附近）尝试撑价 → 卖方压过，价格跌至低位
        收盘在紫色区域 → 卖方掌控最终结果
  信号：看跌延续。开盘区的金色是"死亡挣扎"，并非真正的多方力量。
  操作：跌破本 K 线低点即可顺势做空，止损置开盘高点以上。
```

---

### 5.2 下跌红 K 线：上紫下金 ⚠️ 潜在看涨背离（低位吸筹）

```
  开盘（顶）
  ┌────────────────────────┐
  │ ░░░░░░░░░░░░░░░░░░░░░░░│  ← 紫色：卖方发动下跌（开盘处主动卖出）
  │ ░░░░░░░░░░░░░░░░░░░░░░░│
  ├────────────────────────┤
  │ ███████████████████████│  ← 金色：低位买方大量承接！
  │ ███████████████████████│
  └────────────────────────┘
  收盘（底）                    Delta: 混合，可能接近 0

  叙事：卖方把价格从开盘打下来（紫色在高位）
        但买方在低位大量接货（金色在收盘区）
        K 线虽然收红，但"结局"是买方在主导
  信号：若金色部分颜色深（高量）→ 机构在低位吸筹，强力看涨背离。
        若金色颜色浅（低量）→ 象征性承接，信号弱，需等待后续确认。
  操作：结合 Vol Profile 查看当前价格是否在 VAL 或 OB 附近，
        若是，本 K 线收盘后可轻仓建多，止损置 K 线低点之下。
```

---

### 5.3 下跌红 K 线：全金色 ⚠️ 悖论信号（被动卖单大量出货）

```
  ┌────────────────────────┐
  │ ███████████████████████│
  │ ███████████████████████│  ← 全程金色：买方持续主动
  │ ███████████████████████│
  │ ███████████████████████│
  └────────────────────────┘
  收盘 < 开盘（红 K）           Delta: 正值！但价格下跌

  叙事：买方一直在主动出击（Delta 正），但价格反而跌了
        → 说明挂了大量**限价卖单（被动卖方）**在各个价位
          把所有买方的主动单悉数吸收，并把价格往下推
        这是"出货式吸收"的典型形态
  信号：极度看跌。表面上看金色像是多头信号，实质是机构在借买盘出货。
        结合成交量：若量能异常大 → 大机构在此区间大规模分发头寸。
  操作：绝对不能做多。等下一根 K 线确认方向，若继续跌则顺势做空。
```

### 5.4 上涨绿 K 线：下紫上金 ✅ 强看涨（最健康上涨结构）

```
  收盘（顶）
  ┌────────────────────────┐
  │ ███████████████████████│  ← 金色：收盘附近买方主导，价格以强势结束
  │ ███████████████████████│
  ├────────────────────────┤
  │ ░░░░░░░░░░░░░░░░░░░░░░░│  ← 紫色：开盘低位有卖方，但被买方克服
  │ ░░░░░░░░░░░░░░░░░░░░░░░│
  └────────────────────────┘
  开盘（底）                    Delta: 正值

  叙事：开盘时卖方尝试压价（低位紫色）→ 买方逐步接管 → 以高位金色收盘
        整根 K 线的"叙事弧"是买方从弱转强
  信号：强看涨延续，类似于价格从低位扫过卖方后发力上攻。
  操作：可在本 K 线回踩中间过渡区做多，止损置紫色区最低点之下。
```

### 5.5 上涨绿 K 线：下金上紫 ⚠️ 潜在高位阻力（吸收顶部）

```
  收盘（顶）
  ┌────────────────────────┐
  │ ░░░░░░░░░░░░░░░░░░░░░░░│  ← 紫色：高位出现大量卖单！
  │ ░░░░░░░░░░░░░░░░░░░░░░░│
  ├────────────────────────┤
  │ ███████████████████████│  ← 金色：低位买方推价上来
  │ ███████████████████████│
  └────────────────────────┘
  开盘（底）                    Delta: 混合

  叙事：买方从低位推价上涨（金色在开盘/低位）
        但收盘价附近出现大量主动卖方（紫色在高位/收盘区）
        K 线虽收绿，收盘区是紫色 = 卖方掌控了价格最终落点
  信号：若紫色部分颜色深（大成交量 + 卖方大幅占优）→ 高位压力显著，上涨受阻风险高。
        结合 Vol Profile：若收盘价附近恰好是 VAH 或前高 → 压力更强。
  操作：不宜追多；做多持仓者考虑减仓；等待下一根确认是否能继续突破。
```

### 5.6 上涨绿 K 线：全紫色 ⚠️ 悖论信号（被动买单大量入场）

```
  ┌────────────────────────┐
  │ ░░░░░░░░░░░░░░░░░░░░░░░│
  │ ░░░░░░░░░░░░░░░░░░░░░░░│  ← 全程紫色：卖方持续主动
  │ ░░░░░░░░░░░░░░░░░░░░░░░│
  │ ░░░░░░░░░░░░░░░░░░░░░░░│
  └────────────────────────┘
  收盘 > 开盘（绿 K）           Delta: 负值！但价格上涨

  叙事：卖方一直在主动出击（Delta 负），但价格反而涨了
        → 说明有大量**限价买单（被动买方）**托住了所有卖单，并把价格往上推
        这是"吸收式建仓"的典型形态
  信号：极度看涨。机构在此区间大量买入限价单，拦截所有主动卖单。
        结合成交量：量能越大，机构建仓意图越明显。
  操作：若在重要支撑位（OB / VAL / BOS 确认后），可积极做多，止损置 K 线低点。
```

### 5.7 颜色强度（Alpha）的信息量

颜色的**深浅**直接反映该价位的成交量大小和买卖比例的强弱：

```
  ████  深金色  →  该价位：大成交量 + 买方大幅占优  →  强力多头支撑
  ░░░░  浅紫色  →  该价位：小成交量 + 卖方略微占优  →  弱信号，可忽略
  ░░░░  深紫色  →  该价位：大成交量 + 卖方大幅占优  →  强力空头压力
```

**实战规则：只信颜色深的区域。** 颜色浅（alpha 低）的 bin 代表成交量极低，
不构成有意义的订单流信号，不要过度解读。

### 5.8 综合判读速查表

| K 线颜色 | 上半颜色 | 下半颜色 | 整体 Delta | 含义 | 信号强度 |
|---------|---------|---------|-----------|------|---------|
| 红（跌） | 金 | 紫 | 符号不定¹ | 买方开盘失守，卖方掌控收盘；Delta>0 时见注² | 🔴 强空 |
| 红（跌） | 紫 | 金 | 符号不定¹ | 卖方打下，买方低位接货 | 🟡 潜在多 |
| 红（跌） | 金 | 金 | 正（！） | 被动卖单大量出货 | 🔴 极度看空 |
| 红（跌） | 紫 | 紫 | 负 | 干净下跌，无分歧 | 🔴 强空 |
| 绿（涨） | 金 | 紫 | 符号不定¹ | 开盘卖压，收盘买方掌控；Delta<0 时见注² | 🟢 强多 |
| 绿（涨） | 金 | 金 | 正 | 干净上涨，无分歧 | 🟢 强多 |
| 绿（涨） | 紫 | 金 | 符号不定¹ | 买方从低位推价，收盘区（高位）遭遇卖方阻击 | 🟡 潜在空 |
| 绿（涨） | 紫 | 紫 | 负（！） | 被动买单大量吸筹 | 🟢 极度看多 |

> ¹ **符号不定**：上下两半颜色相反，整体 Delta 正负取决于哪半边的绝对成交量更大，
> 可能为正、为负或接近 0。这类 K 线不应依赖整体 Delta 判断，颜色分布本身才是信息。
>
> ² **"意外方向" Delta**（混色 K 线中 Delta 与颜色"优势侧"相反）：
> - **绿K + 上金下紫 + Delta<0**：主动卖方量更大，但价格仍涨 → 低位存在大量被动限价买单吸收了全部主动卖压，吸收式上涨，看涨信号增强。
> - **红K + 上金下紫 + Delta>0**：主动买方量更大，但价格仍跌 → 高位存在大量被动限价卖单吸收了全部主动买盘，吸收式下跌，看跌信号增强。
> - **绿K + 上紫下金 + Delta<0**：下半金色买方量不足以抵消上半紫色卖压 → 信号弱，等待后续确认。
> - **红K + 上紫下金 + Delta>0**：上半紫色卖方量不足以抵消下半金色买压 → 潜在低位吸筹，信号增强。
>
> 注：「上半」指 K 线价格范围的上半部分（靠近高点），「下半」靠近低点。
> 开盘/收盘在上半还是下半取决于 K 线是红还是绿。

## 六、不同价格结构下的订单流叙事

同样的 Delta 和 Heatmap 组合，在不同价格结构位置下含义截然不同。以下按结构位分类列出核心叙事。

---

### 6.1 FVG（Fair Value Gap / 公允价值缺口）

FVG 是快速单边行情留下的"未成交真空"，价格回填时是最常见的入场窗口。

| 场景 | 订单流信号 | 叙事 |
|------|-----------|------|
| 价格回踩 FVG 上沿，Delta 转正 | 买方在缺口边缘主动入场 | 缺口有效防守，延续上涨 |
| 价格回踩 FVG，Delta 负但 Heatmap 下金（被动买吸收） | 卖方主动打压，但限价买单在 FVG 底部承接 | 吸收式确认，更强的多头信号 |
| 价格跌穿 FVG，Delta 持续负，无吸收 | 卖方主动推价，无被动买方抵抗 | FVG 失效，看跌延续 |
| 价格填满 FVG 后 Delta 骤降至 0 | 缺口已被充分交易，买力耗尽 | FVG 磁吸效应结束，方向待定 |

---

### 6.2 OB（Order Block / 订单块）

OB 是机构建仓/平仓的"脚印"，价格回测时机构有动机在此再次操作。

| 场景 | 订单流信号 | 叙事 |
|------|-----------|------|
| 回测看涨 OB，Delta 正 + Heatmap 金色 | 主动买方在 OB 区域积极参与 | 机构二次建多，强多信号 |
| 回测看涨 OB，Delta 负但价格不破 | 卖方主动打压，被 OB 内被动买单全部吃掉 | 吸收守位，信号质量更高（机构限价买单密集） |
| 回测看涨 OB，Delta 负 + 价格跌穿 | 卖方主动推价，OB 内无足够被动买单 | OB 失效，原结构被打破 |
| 回测看跌 OB，Delta 负 + Heatmap 紫色 | 机构主动做空，结构清晰 | 空头延续 |

---

### 6.3 BOS / CHoCH 结构位

结构突破（BOS）确认趋势延续，结构转换（CHoCH）标志反转启动。订单流决定突破真假。

| 场景 | 订单流信号 | 叙事 |
|------|-----------|------|
| BOS 突破时 Delta 大幅正值 | 主动买方主导突破，量价配合 | 真实突破，趋势延续可信 |
| BOS 突破时 Delta 接近 0 或负 | 突破靠被动撮合推完成，主动买方缺席 | 假突破风险高，警惕回踩后直接反转 |
| CHoCH 成立时 Delta 转向（从负转正） | 原卖方主导 → 买方开始反压 | 反转启动有主动资金参与，可信度高 |
| CHoCH 成立但 Delta 未转向 | 价格虽创结构新高，但卖方仍是主动方 | 结构转换可能只是洗盘，需等待 Delta 确认 |

---

### 6.4 POC（Point of Control / 最大成交量价位）

POC 是市场"认为公平"的价格中枢，是多空分歧最大、争夺最激烈的价位。

| 场景 | 订单流信号 | 叙事 |
|------|-----------|------|
| 价格在 POC 徘徊，Delta 震荡接近 0 | 多空势均力敌，无方向性压制 | 等待，不宜入场；等 Delta 出现持续偏向 |
| 价格从下方突破 POC，Delta 持续正 | 买方主动推价穿越争议区 | 价格接受区上移，偏多 |
| 价格从上方跌破 POC，Delta 持续负 | 卖方主动推价跌入争议区 | 价格接受区下移，偏空 |
| POC 附近出现高量 + Delta ≈ 0 | 双方在此大量撮合，但无方向 | 吸收/消耗博弈，等突破方向再跟进 |

---

### 6.5 VAH / VAL（价值区边界）

VAH（价值区上沿）和 VAL（价值区下沿）是市场"接受"与"拒绝"的分界线。

| 价格位置 | 订单流信号 | 叙事 |
|---------|-----------|------|
| 价格在 VAL 附近，Delta 正 + 吸收 | 买方在价值区下沿主动承接，被动买单配合 | 多方守住价值区，强支撑；可做多，止损 VAL 下方 |
| 价格跌穿 VAL，Delta 持续负，无吸收 | 卖方主动推价，价值区被放弃 | 价值区失守，下方 LVN 快速穿越，目标下一个 HVN |
| 价格在 VAH 附近，Delta 负 + 吸收 | 卖方在价值区上沿主动压制，被动卖单拦截买盘 | 空方守住价值区，强压力；可做空，止损 VAH 上方 |
| 价格突破 VAH，Delta 持续正 | 买方主动突破，卖方无法吸收 | 价值区上移，追多有效 |

---

### 6.6 LVN（Low Volume Node / 低量节点）

LVN 是历史成交稀少的价格区间，价格在此缺乏摩擦力，倾向于快速穿越。

| 场景 | 订单流信号 | 叙事 |
|------|-----------|------|
| 价格进入 LVN，任意方向 Delta | Delta 方向即为穿越方向 | 无需等待强信号，顺 Delta 方向快速入场，目标下一个 HVN |
| 价格在 LVN 内停留 + 高量 + Delta ≈ 0 | 异常：本不该有大量成交，出现吸收 | 隐性机构订单，该价位比表面看起来更重要；止损收紧观察 |
| 价格到达 LVN 边缘被弹回，Delta 反转 | 穿越尝试失败，主动方力量不足 | 假突破，回归 HVN；反向入场机会 |

## 七、Vol Profile 配合订单流

```
  价格轴
    │
  高 ├── VAH（价值区上沿）─────────────────────────── 压力
    │        █ █ █ █ █ █ █ ← 高量区（多方/空方激烈争夺）
    │      █ █ █ █ █ █ █ █ █
 POC├── ██ █ █ █ █ █ █ █ █ ██ ← 最大成交量（引力中心）
    │      █ █ █ █ █ █ █ █ █
    │        █ █ █ █ █ █ █
  低 ├── VAL（价值区下沿）─────────────────────────── 支撑
    │
    │   █                  ← 低量区 LVN（Low Volume Node）
    │                        价格快速穿越，不会停留
    └──────────────────────────────────────────────── 量轴
```

| Vol Profile 区域 | Delta 信号 | 解读 |
|-----------------|-----------|------|
| 价格在 POC 之上 + 正 Delta | 买方占优 | 价值区内正常，趋势偏多 |
| 价格在 POC 之下 + 正 Delta | 买方尝试回到 POC | 关注是否能突破，失败则继续做空 |
| 价格在 LVN + 任意 Delta | 快速穿越 | 方向判断后，LVN 内不停留，顺势入场 |
| 价格在 VAH 附近 + 负 Delta | 卖方压制 | 高位阻力，空方防守成功的信号 |
| 价格在 VAL 附近 + 正 Delta | 买方承接 | 低位支撑，多方防守成功的信号 |

## 八、综合判读框架

### 信号强度评分（建议 ≥ 4 分再入场）

```
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │  +1分  Delta 与 K 线方向一致（顺势确认）                │
  │  +1分  Heatmap 颜色与方向一致（涨金色 / 跌紫色）        │
  │  +1分  Delta 背离信号（前高/低点的力量对比）            │
  │  +1分  K 线形态有效（锤子/射击之星/吞没等）             │
  │  +1分  Vol Profile 配合（LVN 穿越 / VAH·VAL 防守）      │
  │  +1分  SMC 结构配合（BOS / CHoCH / FVG / OB）           │
  │  +1分  连续 3 根以上同向 Delta（动能持续性）             │
  │                                                         │
  │  ≥ 5分  强信号，全仓按计划入场                          │
  │  3–4分  中等信号，缩仓或等待下一根 K 线确认             │
  │  ≤ 2分  信号不足，旁观                                  │
  └─────────────────────────────────────────────────────────┘
```

### 入场决策流程

```
  开始
    │
    ▼
  SMC 结构是否到位？（BOS/CHoCH/FVG/OB）
    │ 否 → 等待
    │ 是
    ▼
  K 线形态是否有效？（锤子/射击之星/吞没等）
    │ 否 → 等待
    │ 是
    ▼
  Delta 与形态方向是否一致？
    │ 否 → 降低仓位或等待下一根确认
    │ 是
    ▼
  Heatmap 颜色是否配合？（金色做多 / 紫色做空）
    │ 否 → 警惕，查看是否为吸收
    │ 是
    ▼
  Vol Profile：当前价格在支撑区还是 LVN？
    │ LVN → 快速入场，目标高量区
    │ 支撑/压力 → 标准入场，止损置区域之外
    ▼
  入场，记录 Delta 值作为持仓参考基准
```

## 九、持仓管理：用 Delta 判断是否继续持有

入场后，继续监控 Delta 变化：

```
  做多持仓中：
    ✓ 每根 K 线 Delta 持续正值 → 买力健康，继续持有
    ✓ 回调 K 线虽价跌，但 Delta 仍为正 → 正常洗盘，不出
    ✗ 价格新高但 Delta 骤降至接近 0 → 买力衰竭，考虑减仓
    ✗ 出现大幅负 Delta K 线 → 卖方入场，立即检查止损

  做空持仓中：
    ✓ 每根 K 线 Delta 持续负值 → 卖力健康，继续持有
    ✓ 反弹 K 线虽价涨，但 Delta 仍为负 → 正常反弹，不出
    ✗ 价格新低但 Delta 骤升至接近 0 → 卖力衰竭，考虑减仓
    ✗ 出现大幅正 Delta K 线 → 买方入场，立即检查止损
```

## 十、盘口堆叠失衡（Stacked Imbalance）

### 10.1 概念

盘口堆叠失衡描述的是**委托簿深度方向**的压制，而非成交量方向：当买方（Bid）在多个连续深度档位上的挂单量显著超过对应卖方（Ask）挂单量时，称为**看涨堆叠失衡**（Bullish Stacked Imbalance）；反之为**看跌堆叠失衡**。

```
  深度档位  Bid 量    Ask 量   Ratio  判断
  rank 0   2 000     400      5.0    ✔ BID
  rank 1   1 800     350      5.1    ✔ BID
  rank 2   1 600     300      5.3    ✔ BID   ← 3档连续 ≥ threshold → 看涨失衡
  rank 3     900     850      1.1        —
```

与 Delta（成交方向）不同，失衡反映的是**挂单意愿**——大量限价买单堆叠在多档意味着潜在的支撑墙；大量限价卖单堆叠则构成压力墙。

### 10.2 在 Liquidity Heatmap 中的显示

| 颜色 | 方向 | 含义 |
|------|------|------|
| **蓝色竖条** | 看涨 | 连续多档 bid 量 ÷ ask 量 ≥ Ratio 阈值 |
| **橙色竖条** | 看跌 | 连续多档 ask 量 ÷ bid 量 ≥ Ratio 阈值 |

竖条的纵向跨度对应失衡覆盖的价格区间（rank 0 到触发失衡的最深档位）。

**工具栏参数：**

| 参数 | 默认 | 说明 |
|------|------|------|
| Lvl | 3 | 最少连续失衡档位数；提高可减少噪音 |
| Ratio | 3.0 | 单档 bid/ask（或 ask/bid）比值阈值 |
| Depth | 10 | 最多分析多少档深度；超过此档位的挂单视为噪音 |

### 10.3 实战解读

```
  场景 1 — 价格接近看涨失衡区（蓝条）
  ┌──────────────────────────┐
  │  ████████  ← 蓝条（bid 墙）
  │  ████████
  │  ████████
  └──────────────────────────┘
  价格从上方接近 → bid 墙提供支撑
  Delta 同步出现正值 → 主动买方配合 → 信号强
  价格穿越蓝条而无反弹 → 支撑失效，bid 墙已被吃穿或撤单
```

```
  场景 2 — 价格接近看跌失衡区（橙条）
  ┌──────────────────────────┐
  │  ░░░░░░░░  ← 橙条（ask 墙）
  │  ░░░░░░░░
  │  ░░░░░░░░
  └──────────────────────────┘
  价格从下方接近 → ask 墙提供压力
  Delta 同步出现负值 → 卖方主动配合 → 信号强
  价格突破橙条 → ask 墙撤单或被消化，方向可能转换
```

### 10.4 注意事项

- **挂单 ≠ 真实意图**：大量挂单可能是 Spoof（见第四节），与 Spoof 覆盖层结合判断；
  若失衡区与 Spoof 标记重合，可信度大幅降低。
- **快照时效**：失衡基于单一盘口快照评估，下一个快照可能已完全改变；连续多个快照均显示
  同方向失衡，可信度更高。
- **配合价格结构**：失衡区叠加在 OB / FVG / VAL / VAH 等结构位时，信号质量最佳；
  空旷区间内的孤立失衡通常意义有限。

## 十一、常见误区

| 误区 | 正确理解 |
|------|----------|
| Delta 正 = 价格一定涨 | Delta 只说明谁更积极，被动方可以吸收所有主动单而价格不动 |
| 大 Delta = 真实趋势 | 大 Delta 可能是"吸收"——限价单将市价单全部消化，价格反向 |
| 金色 K 线就做多 | 金色只说明该 K 线买方主动，还需看 K 线形态和所在结构位置 |
| 紫色 K 线就做空 | 同上，紫色只是卖方主动信号，脱离结构的紫色 K 线意义有限 |
| Vol 高量区是阻力 | 高量区可支撑也可压力，取决于价格从哪个方向接近 |
